# v0.1 Spec

## Goal

A user can write a journal entry and see the garden change.

## Must Have

- Write a journal entry
- Save journal entries
- Preserve data after reload
- Analyze journal text with a simple rule
- Give water when meaningful/positive content is detected
- Grow the garden based on water
- Deploy to a public URL

## Not in v0.1

- Login
- Social feed
- Following users
- Likes
- Public journal entries
- Advanced AI analysis
- Full pixel-art graphics
- Mobile app
- Notifications

## Release Condition

v0.1 is released when a third party can:

1. Open the public URL
2. Write a journal entry
3. Save it
4. See the garden change
